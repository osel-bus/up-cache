# up-cache

Georeferencované územní plány obcí pro skill `overeni-pozemku`.
Formát a postup: `references/georeference.md` ve skillu.

Obec se do `index.json` zapisuje až po kontrole (meta.json → `kontrola`).
Data jsou pomůcka pro prověrku; funkční plochu do projektové dokumentace vždy potvrdit v originálním výkresu.
